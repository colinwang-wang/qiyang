# 内容更新指南

## 更新 NEWS

编辑 `src/content/news.json`，按以下格式添加新条目（最新的放最前面）：

```json
[
  {
    "id": "2",
    "title": "文章标题",
    "date": "2026-05-07",
    "summary": "摘要，显示在列表中",
    "content": "正文内容"
  },
  {
    "id": "1",
    "title": "旧文章...",
    ...
  }
]
```

## 更新产品

### 添加新系列

1. 编辑 `src/content/products/` 下对应的 JSON 文件
2. 在 `series` 数组中添加新条目：

```json
{
  "name": "NEW Series",
  "slug": "new-series",
  "image": "new-image.png",
  "images": ["new-image.png", "new-image-2.png"],
  "specs": {
    "Operating Temperature": "-55℃ ~ +125℃",
    "Rated Current": "3A"
  }
}
```

3. 将产品图片放到 `public/images/products/` 目录

### 添加新类别

1. 在 `src/content/products/` 下创建新的 JSON 文件
2. 更新 `src/content/products/index.json`
3. 更新相关页面路由

## 部署更新

修改完成后执行：

```bash
npm run build
```

然后将 `dist/` 目录部署到服务器。

如果用 GitHub 管理，直接 push 即可触发自动部署。
