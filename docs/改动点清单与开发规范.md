## 二、开发规范

### 技术栈

| 层面 | 选型 | 说明 |
|------|------|------|
| 框架 | Astro 4.0 | 静态生成，零 JS 默认 |
| 交互组件 | React 18 | 仅用于轮播、移动端菜单等 Islands |
| 样式 | Tailwind CSS 3.4 | 原子化 CSS，不写自定义 CSS 文件 |
| 动画 | Framer Motion | 轮播过渡、滚动淡入 |
| 图标 | Lucide React | 统一图标库 |
| 图片优化 | Astro Image | 自动 WebP/AVIF 转换 |
| 部署 | Vercel / Cloudflare Pages | 静态托管 + CDN |

### 目录结构

```
/src
  /components
    /ui/              # 原子组件：Button, Card, Badge
    /layout/          # Header, Footer, MobileNav
    /sections/        # 页面区块：HeroCarousel, ProductGrid, AboutContent
  /content
    /products/        # 产品数据 JSON（按类别组织）
    /company/         # About Us 文案 Markdown
  /pages
    index.astro
    products.astro
    products/[category]/index.astro
    products/[category]/[subcategory].astro
    products/[category]/[subcategory]/[product].astro
    applications.astro
    news.astro
    about.astro
    contact.astro
  /layouts
    BaseLayout.astro  # HTML 骨架 + SEO Meta
  /assets/images
    /factory/         # 工厂图片
    /products/        # 产品图
    /applications/    # 应用场景图
    /carousel/        # 首页轮播图
    /brands/          # 国际品牌 Logo
```

### 编码规范

1. **组件命名**：PascalCase，文件名与组件名一致
   - Astro 组件：`HeroCarousel.astro`
   - React Islands：`MobileNav.tsx`

2. **样式规范**：
   - 全部使用 Tailwind 工具类，禁止内联 style
   - 响应式断点：`sm:640px` / `md:768px` / `lg:1024px` / `xl:1280px`
   - 移动端优先（Mobile First）

3. **图片规范**：
   - 使用 Astro `<Image>` 组件，自动优化
   - 必须提供 `alt` 属性（英文描述）
   - 轮播图尺寸统一：1920×600（建议）
   - 产品图：正方形 800×800 或 4:3 比例

4. **SEO 规范**：
   - 每页必须有唯一 `<title>` 和 `<meta description>`
   - 使用语义化 HTML 标签（`<nav>`, `<main>`, `<article>`, `<section>`）
   - 图片提供 alt text
   - 生成 sitemap.xml

5. **性能目标**：
   - LCP < 2.5s
   - CLS < 0.1
   - 首屏无阻塞 JS（Astro 默认零 JS）
   - 图片懒加载（首屏轮播除外）

6. **产品数据管理**：
   - 产品信息以 JSON 文件存储在 `/src/content/products/`
   - 按类别分文件：`rectangular-connector.json`, `circular-connector.json` 等
   - 结构示例：
   ```json
   {
     "category": "RECTANGULAR CONNECTOR",
     "slug": "rectangular-connector",
     "products": [
       {
         "id": "rc-001",
         "name": "Product Name",
         "image": "/images/products/rc-001.jpg",
         "specs": {
           "contacts": "10-100",
           "voltage": "500V",
           "current": "5A"
         }
       }
     ]
   }
   ```

7. **Git 规范**：
   - 分支：`main`（生产）/ `dev`（开发）/ `feature/*`
   - Commit 格式：`feat: add hero carousel` / `fix: mobile nav z-index`
   - PR 合并前需本地构建通过

8. **国际化预留**：
   - 文案集中管理，不硬编码在组件中
   - 路由结构预留 `/en/`, `/zh/` 前缀扩展能力
