# 部署手册

## 一、GitHub Pages 展示（当前配置）

当前已配置好，推送到 main 分支后自动部署。

- 访问地址：`https://colinwang-wang.github.io/qiyang`
- 需要在 GitHub 仓库 Settings → Pages → Source 选择 `GitHub Actions`

## 二、正式服务器部署（域名根路径）

### 修改配置

修改 `astro.config.mjs`：

```js
export default defineConfig({
  site: 'https://www.sz-qy.com.cn',
  // 删除 base 或改为 '/'
  integrations: [react(), tailwind(), sitemap()],
});
```

### 构建

```bash
npm install
npm run build
```

产出目录：`dist/`，包含所有静态文件，直接部署即可。

### 部署方式

#### 方式 A：Nginx（推荐）

将 `dist/` 目录内容上传到服务器，Nginx 配置：

```nginx
server {
    listen 80;
    server_name www.sz-qy.com.cn sz-qy.com.cn;

    root /var/www/qiyang;
    index index.html;

    # 301 重定向裸域名到 www
    if ($host = sz-qy.com.cn) {
        return 301 https://www.sz-qy.com.cn$request_uri;
    }

    location / {
        try_files $uri $uri/ $uri/index.html =404;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|webp|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

#### 方式 B：Vercel

1. 连接 GitHub 仓库到 Vercel
2. Framework Preset 选 `Astro`
3. 环境变量无需设置
4. 绑定自定义域名 `www.sz-qy.com.cn`

#### 方式 C：Cloudflare Pages

1. 连接 GitHub 仓库
2. Build command: `npm run build`
3. Build output directory: `dist`
4. 绑定域名

### 同时保留 GitHub Pages 展示

如果想同时保留 GitHub Pages 作为预览，正式部署用根路径，可以用环境变量控制：

修改 `astro.config.mjs`：

```js
const isGitHubPages = process.env.GITHUB_ACTIONS === 'true';

export default defineConfig({
  site: isGitHubPages ? 'https://colinwang-wang.github.io' : 'https://www.sz-qy.com.cn',
  base: isGitHubPages ? '/qiyang' : '/',
  integrations: [react(), tailwind(), sitemap()],
});
```

这样：
- GitHub Actions 部署时自动带 `/qiyang` 前缀
- 本地构建或其他服务器部署时使用根路径

## 三、DNS 配置（正式上线时）

将域名 `www.sz-qy.com.cn` 解析到服务器 IP：

| 类型 | 主机记录 | 记录值 |
|------|---------|--------|
| A | www | 服务器IP |
| A | @ | 服务器IP |

如果用 Vercel/Cloudflare，按平台提示配置 CNAME。
